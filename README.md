# ВС-Логистика — главная страница (desktop)

Статическая версия главной страницы сайта эвакуатора «ВС-Логистика». Сборщики и фреймворки не нужны: откройте `index.html` в браузере или опубликуйте папку на любом статическом хостинге (например, GitHub Pages).

> Зафиксирована **desktop-версия** (проверена на 1440 и 1600 px). Мобильная версия — следующий этап. Сейчас при ширине меньше 1120 px главный экран просто встаёт в одну колонку.

## Структура

```
vs-logistika-site/
├── index.html          — главная страница: весь контент в HTML (SEO)
├── spb-map.html        — карта экипажей, встраивается в index.html через <iframe>
├── css/
│   ├── styles.css      — стили страницы, сгруппированы по секциям
│   └── map.css         — стили карты
├── js/
│   ├── main.js         — логика: расчёт вызова, геолокация, формы, связь с картой
│   └── map.js          — карта: районы, статусы, точки экипажей, панель района
└── assets/
    ├── favicon.svg
    └── photos/         — сюда класть реальные фото (см. ниже)
```

## Внешние зависимости (CDN)

| Что | Откуда | Где используется |
|---|---|---|
| Leaflet 1.9.4 (JS + CSS) | `unpkg.com/leaflet@1.9.4` (с SRI) | `spb-map.html` |
| Тайлы карты | `tile.openstreetmap.org` | карта в hero и мини-карта в кейсе |
| Шрифты Onest, JetBrains Mono | Google Fonts | все страницы |

Для продакшена при большой нагрузке: тайлы OpenStreetMap стоит заменить на коммерческого провайдера (MapTiler, Stadia, Яндекс и т. п.), так как политика OSM не рассчитана на высокий трафик. Атрибуцию «© OpenStreetMap» сохранить.

## Локальный запуск

Страница работает и при открытии файла напрямую, но геолокация и обмен сообщениями с картой надёжнее работают через локальный сервер:

```
npx serve .        # или: python3 -m http.server 8080
```

## Как устроена интерактивность

- **Расчёт вызова** (секция `#calc`) — 4 шага: где автомобиль → куда везём → что случилось → какой автомобиль, затем экран результата. Если ситуацию выбрали в блоке «Что случилось?», шаг 3 пропускается. Состояние сохраняется в `localStorage` под ключом `vsl-calc-v3`.
- **Кнопки «Вызвать эвакуатор»** ведут к расчёту. Если адрес введён на главном экране, расчёт начинается с шага 2.
- **Карта**: по клику на район открывается панель с ориентиром подачи и кнопками. Кнопка «Вызвать эвакуатор» в панели отправляет `postMessage` на страницу, та подставляет район и прокручивает к расчёту. «Определить, где я» передаёт координаты карте, и она показывает ближайший район.
- **Формы** просят только телефон, комментарий необязателен. **Отправка на сервер пока не подключена**: заявка показывает подтверждение на странице. Подключите свой endpoint или CRM в функции `send` в `js/main.js`.
- Разметка связана с логикой через `data-*` атрибуты (описание в начале `js/main.js`). Весь текстовый контент (услуги, районы, цены, FAQ, кейсы) лежит в HTML и индексируется.

## Что нужно заменить перед запуском

1. **Фото.** Каждое место под фото — `<div class="photo" data-photo="…">`. Замените на `<img class="photo-img" src="assets/photos/….jpg" alt="…">`. Нужны только реальные фото компании, без стоков:

| data-photo | Что снять |
|---|---|
| `complex-hero` | Реальное фото, крупно: манипулятор поднимает автомобиль из кювета |
| `complex-2` | Реальное фото: погрузка после ДТП |
| `complex-3` | Реальное фото: перевёрнутый авто / сложный доступ |
| `case-1` | Реальное фото с этой эвакуации: погрузка, тележки под колёсами |
| `case-2` | Реальное фото с этой эвакуации |
| `case-3` | Реальное фото с этой эвакуации |
| `fleet-1` | Фото: сдвижная платформа |
| `fleet-2` | Фото: тележки под колёсами |
| `fleet-3` | Фото: манипулятор в работе |
| `fleet-4` | Фото: грузовой эвакуатор |

2. **Цены.** В блоке «Цены по СПб» стоит «от ··· ₽» (тарифы на согласовании). Чек в блоке цены и суммы в кейсах — демо-цифры.
3. **Кейсы** (`CASES` в `js/main.js` и разметка в `index.html`) — демо-данные. Нужны реальные: авто, район, маршрут, техника, время подачи, стоимость.
4. **Статусы на карте** (`D` в `js/map.js`): количество экипажей, свободные машины и время подачи сейчас смоделированы. Позиции точек условные. Формулировка «Эвакуаторы на линии в реальном времени» относится к статусам, а не к GPS-координатам.
5. **Ссылки** на внутренние страницы (`/ceny/`, `/manipulyator/`, `/evakuator-…-rayon/` и т. д.) соответствуют утверждённой SEO/GEO-структуре. Сами страницы в комплект не входят.
